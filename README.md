# AIR - private jet landing page (React + Vite)

## Run
```powershell
npm install
npm run dev
```
Open the address from the terminal (usually http://localhost:5173).

## Images
Put images into `public/images/` (file names are listed in `public/images/README.txt`).
All paths are in `src/data/images.js`. Until a file is added, a dashed placeholder with its name is shown.

## Build
```powershell
npm run build
```
